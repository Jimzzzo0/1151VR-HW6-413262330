1. **物件產生間隔 (`span`)**：數值越小，物品掉落越頻繁。
2. **物件掉落速度 (`dropSpeed`)**：負值越大，物品下墜速度越快。
3. **炸彈出現比例 (`ratio`)**：以 1～10 的亂數骰子判定（例如 `ratio = 2` 代表 20% 機率為炸彈）。
